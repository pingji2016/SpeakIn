# SpeakIn 模型离线部署指南

SpeakIn 依赖两个离线模型：

| 模型 | 用途 | 大小 | Gradle 下载命令 |
|------|------|------|----------------|
| **whisper-tiny** (ExecuTorch) | 语音转文字 (ASR) | ~233 MB | `.\gradlew downloadWhisperModel` |
| **Qwen3-0.6B** (GGUF) | 文字润色 (LLM) | ~400 MB | `.\gradlew downloadLlmModel` |

> 两个模型都从 HuggingFace 镜像站 (`hf-mirror.com`) 下载，国内网络可直接访问，**无需科学上网**。

---

## 1. 一键下载（推荐）

### 下载全部模型

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew downloadAllModels
```

### 分别下载

```powershell
# 仅下载 ASR 模型（whisper-tiny, ~233MB）
.\gradlew downloadWhisperModel

# 仅下载润色模型（Qwen3-0.6B, ~400MB）
.\gradlew downloadLlmModel
```

### 下载到哪里？

| 模型 | 下载目录 |
|------|---------|
| whisper-tiny | 项目根目录 `whisper_models/` |
| Qwen3-0.6B | 项目根目录 `llm_models/` |

Gradle 任务执行完成后会自动输出 ADB 推送命令。已下载的文件会跳过（支持断点续传）。

---

## 2. 推送到手机

### 2.1 前提

1. 手机开启 **开发者选项** + **USB 调试**
2. 电脑安装 [ADB](https://developer.android.com/studio/releases/platform-tools)（Android Studio 自带路径：`%USERPROFILE%\AppData\Local\Android\Sdk\platform-tools\adb.exe`）
3. 手机 USB 连接电脑，`adb devices` 确认显示 `device`

### 2.2 推送 whisper ASR 模型

```powershell
adb shell mkdir -p /data/data/com.speakin.app/files/whisper/
adb push .\whisper_models\whisper_tiny_xnnpack_fp32.pte ^
  /data/data/com.speakin.app/files/whisper/
adb push .\whisper_models\tokenizer.json ^
  /data/data/com.speakin.app/files/whisper/
```

### 2.3 推送 Qwen3 润色模型

```powershell
adb shell mkdir -p /data/data/com.speakin.app/files/models/
adb push .\llm_models\qwen3-0.6b-q4_k_m.gguf ^
  /data/data/com.speakin.app/files/models/
```

### 2.4 验证推送结果

```powershell
adb shell ls -lh /data/data/com.speakin.app/files/whisper/
adb shell ls -lh /data/data/com.speakin.app/files/models/
```

## 3. 验证模型生效

打开 SpeakIn App，进入笔记详情页。正常时：

- **ASR 模型**：录音后自动转写，日志可见 `ExecuTorchWhisper: Model loaded`
- **润色模型**：转写完成后自动润色，日志可见 `LocalLlmEngine: Model loaded`

### 查看运行日志

```powershell
# ASR 日志
adb logcat -s ExecuTorchWhisper,AsrEngineImpl,AsrModelManager

# LLM 日志
adb logcat -s LocalLlmEngine,ModelManager
```

正常日志示例：
```
ExecuTorchWhisper: Model loaded: .../whisper_tiny_xnnpack_fp32.pte
ExecuTorchWhisper: Available methods: encode, decode
AsrEngineImpl: Whisper engine loaded successfully
```

## 4. 备选方案（不用 Gradle）

> 仅当 Gradle 任务无法运行时使用。

### 浏览器直接下载

| 模型 | 下载链接 |
|------|---------|
| whisper-tiny .pte | https://hf-mirror.com/software-mansion/react-native-executorch-whisper-tiny/resolve/main/xnnpack/whisper_tiny_xnnpack_fp32.pte |
| tokenizer.json | https://hf-mirror.com/software-mansion/react-native-executorch-whisper-small/resolve/main/tokenizer.json |
| Qwen3-0.6B GGUF | https://hf-mirror.com/Qwen/Qwen3-0.6B-GGUF/resolve/main/Qwen3-0.6B-Q4_K_M.gguf |

### PowerShell 下载（替代 curl）

```powershell
# whisper .pte
Invoke-WebRequest -Uri "https://hf-mirror.com/software-mansion/react-native-executorch-whisper-tiny/resolve/main/xnnpack/whisper_tiny_xnnpack_fp32.pte" -OutFile "whisper_tiny_xnnpack_fp32.pte"

# tokenizer
Invoke-WebRequest -Uri "https://hf-mirror.com/software-mansion/react-native-executorch-whisper-small/resolve/main/tokenizer.json" -OutFile "tokenizer.json"

# Qwen3 GGUF
Invoke-WebRequest -Uri "https://hf-mirror.com/Qwen/Qwen3-0.6B-GGUF/resolve/main/Qwen3-0.6B-Q4_K_M.gguf" -OutFile "qwen3-0.6b-q4_k_m.gguf"
```

## 5. 常见问题

### Q: `adb push` 报错 `Permission denied`

debug 构建的 App 可用 `run-as` 绕过：

```powershell
adb push whisper_tiny_xnnpack_fp32.pte /data/local/tmp/
adb shell run-as com.speakin.app mkdir -p files/whisper/
adb shell run-as com.speakin.app cp /data/local/tmp/whisper_tiny_xnnpack_fp32.pte files/whisper/
```

### Q: 模型文件推了但 App 仍提示下载/转写失败

```powershell
# 1. 检查文件是否存在且大小正确
adb shell ls -lh /data/data/com.speakin.app/files/whisper/
adb shell ls -lh /data/data/com.speakin.app/files/models/

# 2. 查看日志定位问题
adb logcat -s AsrEngineImpl,ExecuTorchWhisper,LocalLlmEngine,ModelManager
```

### Q: App 日志显示模型加载失败

常见原因：
- **文件不完整**：下载中断，重新执行 Gradle 任务
- **路径不对**：确认推送到 `/data/data/com.speakin.app/files/whisper/` 而非别的目录
- **App 未启动过**：先打开一次 App 再推模型（否则文件夹不存在）

### Q: whisper-tiny 精度够吗？

whisper-tiny（39M 参数）在日常对话场景效果良好。如果需要更高精度，可改用 whisper-small（244M 参数），参考 [ExecuTorch+Whisper集成文档](./ExecuTorch+Whisper集成文档.md) 中的模型对比表。
