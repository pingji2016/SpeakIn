# SpeakIn 模型离线部署指南

## 概述

SpeakIn 使用 Qwen3-0.6B-Q4_K_M 作为本地润色模型（GGUF 格式，约 **400MB**）。由于 HuggingFace 在国内的网络访问不稳定，应用内直接下载可能失败。本文档说明如何在 **PC 上下载模型**，再通过 **ADB 推送到手机**。

---

## 1. 模型文件信息

| 项目 | 值 |
|------|-----|
| 模型 | Qwen3-0.6B-Q4_K_M |
| 格式 | GGUF |
| 大小 | ~400 MB |
| 下载文件名 | `Qwen3-0.6B-Q4_K_M.gguf` |
| 手机目标路径 | `/data/data/com.speakin.app/files/models/qwen3-0.6b-q4_k_m.gguf` |
| 原始下载地址 | `https://huggingface.co/Qwen/Qwen3-0.6B-GGUF/resolve/main/Qwen3-0.6B-Q4_K_M.gguf` |

> **注意**：App 中的 `ModelManager` 检测到文件存在且大于 100MB 时会自动跳过下载，直接加载模型。所以只要把文件推送到正确位置，App 就能直接使用。

---

## 2. 在 PC 上下载模型

### 方式 A：从 HuggingFace 官方下载（推荐，需科学上网）

```bash
# 使用 curl
curl -L -o Qwen3-0.6B-Q4_K_M.gguf ^
  https://huggingface.co/Qwen/Qwen3-0.6B-GGUF/resolve/main/Qwen3-0.6B-Q4_K_M.gguf
```

### 方式 B：从 HuggingFace 国内镜像下载（无需科学上网）

使用 HuggingFace 镜像站（`hf-mirror.com`）：

```bash
# 使用 curl（Windows PowerShell）
curl -L -o Qwen3-0.6B-Q4_K_M.gguf ^
  https://hf-mirror.com/Qwen/Qwen3-0.6B-GGUF/resolve/main/Qwen3-0.6B-Q4_K_M.gguf
```

或者使用浏览器直接打开以下链接下载：

- **镜像站（国内快）**：https://hf-mirror.com/Qwen/Qwen3-0.6B-GGUF/resolve/main/Qwen3-0.6B-Q4_K_M.gguf
- **官方源（需科学上网）**：https://huggingface.co/Qwen/Qwen3-0.6B-GGUF/resolve/main/Qwen3-0.6B-Q4_K_M.gguf

### 方式 C：使用 aria2 多线程下载（速度更快）

```bash
# 安装 aria2（Windows 可用 scoop 或 winget）
scoop install aria2
# 或 winget install aria2

# 多线程下载
aria2c -x 4 -s 4 ^
  https://hf-mirror.com/Qwen/Qwen3-0.6B-GGUF/resolve/main/Qwen3-0.6B-Q4_K_M.gguf
```

## 3. 推送模型到手机

### 3.1 前提条件

1. 手机已开启 **开发者选项** 和 **USB 调试**
2. 电脑已安装 Android SDK Platform Tools（含 `adb.exe`）
3. 手机通过 USB 连接到电脑

> 如果电脑没有 ADB，可以从这里下载：[Android SDK Platform Tools](https://developer.android.com/studio/releases/platform-tools)
>
> 或者通过 Android Studio 自带的：`%USERPROFILE%\AppData\Local\Android\Sdk\platform-tools\adb.exe`

### 3.2 检查设备连接

```bash
adb devices
```

输出示例：
```
List of devices attached
ABCDEF12345678    device
```

确保显示 `device` 状态（不是 `unauthorized`）。如果显示 `unauthorized`，请在手机上确认 USB 调试授权。

### 3.3 推送模型文件

```bash
# 1. 在手机上创建 models 目录
adb shell mkdir -p /data/data/com.speakin.app/files/models/

# 2. 推送模型文件（将 下载路径 替换为实际下载目录）
adb push 下载路径\Qwen3-0.6B-Q4_K_M.gguf ^
  /data/data/com.speakin.app/files/models/qwen3-0.6b-q4_k_m.gguf
```

实际执行示例：

```bash
adb shell mkdir -p /data/data/com.speakin.app/files/models/
adb push D:\Downloads\Qwen3-0.6B-Q4_K_M.gguf ^
  /data/data/com.speakin.app/files/models/qwen3-0.6b-q4_k_m.gguf
```

### 3.4 验证文件是否正确推送

```bash
adb shell ls -lh /data/data/com.speakin.app/files/models/qwen3-0.6b-q4_k_m.gguf
```

应该输出类似：
```
-rw-rw---- 1 u0_aXXX u0_aXXX 409M 2026-06-08 12:00 qwen3-0.6b-q4_k_m.gguf
```

文件大小应为约 **400MB**。如果文件很小（如几 KB），说明下载不完整，需要重新下载。

---

## 4. 验证模型生效

1. 拔掉 USB 线（或保持连接）
2. 打开 SpeakIn App
3. 进入 **笔记详情页**（任意一个 Note 或新建一个）
4. App 会自动检测到模型文件已存在，跳过下载，直接加载
5. 如果看到模型加载进度条走完进入主界面，说明部署成功

### 如果 App 仍然提示下载

可能是文件路径不对或文件损坏。按以下步骤排查：

```bash
# 1. 检查文件是否存在及大小
adb shell ls -lh /data/data/com.speakin.app/files/models/

# 2. 如果文件不存在或为 0，重新推送
adb push <你的下载路径>\Qwen3-0.6B-Q4_K_M.gguf ^
  /data/data/com.speakin.app/files/models/qwen3-0.6b-q4_k_m.gguf

# 3. 检查 App 日志
adb logcat -s ModelManager,LocalLlmEngine
```

## 5. 其他模型选择（可选）

如果 400MB 仍然太大，或者手机内存（RAM）较小，可以考虑使用更小的模型：

| 模型 | 大小 | 适用场景 |
|------|------|----------|
| Qwen3-0.6B-Q4_K_M | ~400 MB | **默认推荐**，6GB+ RAM |
| Qwen3-0.6B-Q2_K | ~260 MB | 4-6GB RAM，质量略降 |
| Qwen3-0.6B-Q3_K_M | ~320 MB | 5GB+ RAM，折中方案 |
| Braindler-Q2_K | ~72 MB | 2GB+ RAM，极简润色 |

要更换模型，需要同时修改：

1. **[ModelManager.kt](file:///d:/github/SpeakIn/app/src/main/java/com/speakin/app/domain/llm/ModelManager.kt)** 中的 `MODEL_URL` 和 `MODEL_FILENAME` 常量
2. 推送新模型到手机时，文件名需要与 `MODEL_FILENAME` 保持一致

## 6. 常见问题

### Q: `adb push` 报错 `Permission denied`

**原因**：App 没有以 debug 方式安装，或者手机没有 root。

**解决**：
- 确保 App 是通过 `./gradlew installDebug` 安装的（debug 构建）
- debug 构建的 App 可以通过 `run-as` 访问数据目录：

```bash
# 使用 run-as 方式复制（不需要 root）
adb push D:\Downloads\Qwen3-0.6B-Q4_K_M.gguf /data/local/tmp/
adb shell run-as com.speakin.app mkdir -p files/models/
adb shell run-as com.speakin.app cp /data/local/tmp/Qwen3-0.6B-Q4_K_M.gguf files/models/qwen3-0.6b-q4_k_m.gguf
```

### Q: 下载的 .gguf 文件校验

MD5 校验（下载完成后验证文件完整性）：

```bash
# Windows PowerShell
Get-FileHash Qwen3-0.6B-Q4_K_M.gguf -Algorithm MD5
```

> 注意：HuggingFace 上通常不提供官方 MD5，但文件大小约 409MB 即基本正常。如果差太多说明下载不完整。

### Q: 提示 "No such file or directory"

确认手机已安装 App（至少启动过一次），否则 `/data/data/com.speakin.app/` 目录不存在。

## 7. Whisper ASR 模型部署（ExecuTorch）

从 v1.0.0 起，SpeakIn 使用 **ExecuTorch** 运行 whisper-small 实现离线语音转文字（ASR）。

### 7.1 模型文件清单

| 文件 | 说明 | 大小（约） |
|------|------|-----------|
| `whisper_encoder.pte` | Encoder 模型 | ~90 MB |
| `whisper_decoder.pte` | Decoder 模型 | ~140 MB |
| `whisper_config.json` | 模型配置 | 1 KB |
| `tokenizer.json` | BPE 分词器 | 5 MB |
| **合计** | | **~235 MB** |

手机目标路径：`/data/data/com.speakin.app/files/whisper/`

### 7.2 方式一：使用 Python 脚本导出（推荐）

在 PC 上使用 Python + ExecuTorch 导出 whisper-small：

```bash
# 1. 安装依赖
pip install torch torchaudio executorch

# 2. 运行导出脚本
cd scripts/
python export_whisper_pte.py --model small --output-dir ./exported_whisper

# 3. 推送到手机
adb push ./exported_whisper/ /data/data/com.speakin.app/files/whisper/
```

> **注意**：导出过程需要联网下载 whisper-small 权重，约 500MB。如果网络不稳定，可以使用方式二。

### 7.3 方式二：从 HuggingFace 下载预导出模型

可以从 HuggingFace ExecuTorch 社区下载预导出的 `.pte` 文件：

```bash
# 下载 encoder
curl -L -o whisper_encoder.pte ^
  https://hf-mirror.com/executorch-community/whisper-small/resolve/main/whisper_encoder.pte

# 下载 decoder
curl -L -o whisper_decoder.pte ^
  https://hf-mirror.com/executorch-community/whisper-small/resolve/main/whisper_decoder.pte

# 下载 tokenizer
curl -L -o tokenizer.json ^
  https://hf-mirror.com/openai/whisper-small/raw/main/tokenizer.json
```

或者使用浏览器直接下载：

- https://hf-mirror.com/executorch-community/whisper-small

### 7.4 推送并验证

```bash
# 1. 创建目录
adb shell mkdir -p /data/data/com.speakin.app/files/whisper/

# 2. 推送所有文件
adb push exported_whisper\* /data/data/com.speakin.app/files/whisper/

# 3. 验证
adb shell ls -lh /data/data/com.speakin.app/files/whisper/
```

### 7.5 检查 App 日志

```bash
adb logcat -s ExecuTorchWhisper,AsrEngineImpl,AsrModelManager
```

启动 App 后录音，如果看到以下日志说明加载成功：
```
ExecuTorchWhisper: Encoder loaded: .../whisper_encoder.pte
ExecuTorchWhisper: Decoder loaded: .../whisper_decoder.pte
ExecuTorchWhisper: Mel spectrogram: 80 bands x 94 frames
AsrEngineImpl: Whisper engine loaded successfully
```

### 7.6 录音格式说明

从 v1.0.0 起，录音器已改为 **16kHz 16-bit 单声道 WAV** 格式。这既满足 whisper 的输入要求，又能用 MediaPlayer 播放。旧版本录制的 AAC/MP4 文件不兼容新的 ASR 引擎。
